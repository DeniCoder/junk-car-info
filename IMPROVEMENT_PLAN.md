# План доработки проекта "Брошенная техника"

## Текущее состояние (критические проблемы)

### 1. Отсутствует базовая навигация и UI
- **Проблема**: В шаблоне `base.html` полностью отсутствует меню/шапка сайта
- **Последствие**: Пользователи не могут войти, зарегистрироваться, перейти в профиль или админку
- **Решение**: Добавить полноценную шапку с меню для всех типов пользователей

### 2. Не реализована система аутентификации
- **Проблема**: Отсутствуют страницы входа (`/login`) и регистрации (`/register`)
- **Последствие**: Пользователи не могут создать аккаунт или войти
- **Файлы**: Требуются `app/blueprints/auth/views.py`, шаблоны `login.html`, `register.html`

### 3. Модель данных User не совместима с Flask-Login
- **Проблема**: Класс `User` не наследует `UserMixin`, нет метода `get_id()`
- **Последствие**: Ошибки при использовании `@login_required` и `current_user`
- **Решение**: Добавить `from flask_login import UserMixin`, наследовать класс

### 4. Отсутствует зависимость Flask-Login
- **Проблема**: В `requirements.txt` нет `flask-login`
- **Последствие**: `ModuleNotFoundError: No module named 'flask_login'`
- **Решение**: Добавить в requirements.txt

### 5. База данных не обновлена
- **Проблема**: Новые поля (`user_id`, `appeals`, `notifications`) не добавлены в БД
- **Последствие**: `ProgrammingError: столбец findings.user_id не существует`
- **Решение**: Создать и применить миграции через Flask-Migrate

### 6. Ошибка сериализации в статистике
- **Проблема**: Объекты SQLAlchemy Row не конвертируются в JSON
- **Последствие**: Страница `/admin/stats` падает с ошибкой TypeError
- **Решение**: Конвертировать результаты запросов в словари перед передачей в шаблон

### 7. Документация устарела
- **Проблема**: Файл `claude.md` и README не отражают текущую структуру
- **Последствие**: Непонятно, как запускать проект и какие функции доступны
- **Решение**: Переписать документацию

- Настроить лимиты на:

#### 4.3. Валидация данных
- Санитизация HTML (bleach)
- Проверка размера файлов
- Валидация координат
- Проверка MIME-типов изображений

#### 4.4. HTTPS (для продакшена)
- Настройка редиректа HTTP → HTTPS
- Secure cookies
- HSTS headers

## Инструкция по запуску для разработчика

```bash
# 1. Клонировать репозиторий
git clone -b feature/improvements-analysis https://github.com/DeniCoder/junk-car-info.git
cd junk-car-info

# 2. Создать виртуальное окружение
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env (DATABASE_URL, SECRET_KEY)

# 5. Применить миграции
flask db upgrade

# 6. Создать суперпользователя (опционально)
flask shell
>>> from app import db, create_app
>>> from app.models.user import User
>>> app = create_app()
>>> with app.app_context():
...     admin = User(username='admin', email='admin@example.com', is_admin=True)
...     admin.set_password('securepassword')
...     db.session.add(admin)
...     db.session.commit()

# 7. Запустить сервер
python run.py
# или
flask run

# 8. Открыть в браузере
http://127.0.0.1:5000
```

## Примечания для исполнителя

1. **Не ломать существующий функционал**: Проверять, что карта, создание жалоб и отображение работают после всех изменений.

2. **Тестировать каждый этап**: После выполнения каждого пункта из Приоритета 1 проверять запуск приложения.

3. **Миграции**: Перед применением новых миграций убедиться, что старые применены. Если есть конфликты — создать новую миграцию с нуля.

4. **Стили**: Использовать Bootstrap 5 (подключен в проекте) для консистентности UI.

5. **JavaScript**: Для интерактивности (модалки, уведомления) использовать vanilla JS или минимальные зависимости.

6. **Документация**: После завершения всех работ обновить README с описанием новых функций.
